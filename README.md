# ScreenShotter

Downloads and automatic updates for ScreenShotter, a menu bar screenshot and screen recording app for macOS 26 or later.

**[Download the latest version](https://github.com/soerensteen/ScreenShotter-releases/releases/latest/download/ScreenShotter.zip)**

Unzip, drag ScreenShotter to Applications and open it. macOS asks for Screen Recording permission the first time. The app keeps itself up to date after that.
